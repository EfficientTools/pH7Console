NETWORK SERVER ENTITLEMENT — REQUIRED FOR ON-DEVICE LOCAL AI

pH7Console intentionally includes com.apple.security.network.server only for its bundled on-device language-model runtime. The main app launches the signed `llama-server` command-line helper. It listens only on 127.0.0.1, uses an OS-selected ephemeral port, and requires a new random API key on every launch. The main pH7Console process is its only client.

The helper never binds to 0.0.0.0, ::, a LAN address, or a public interface. It does not advertise a service or provide web, FTP, or file sharing. No prompt or terminal data leaves the Mac. Apple requires a sandbox-inheriting child process to contain only com.apple.security.app-sandbox and com.apple.security.inherit; therefore, the parent must include the server entitlement for this loopback listener to accept the app’s local inference requests.

To verify:
1. Launch pH7Console and select any disposable folder with “Open Workspace.”
2. Press Command-J if needed to show “Local Command Intelligence.”
3. Enter “show the current git branch,” then choose “Create Safe Command Plan.”
4. After warm-up, the local result is labeled “On-device model.”
5. Press Command-B if needed, then open Settings → Privacy → “Authenticated loopback inference.” This shows runtime status and explains the inherited server entitlement.

No account, demo user, subscription, external hardware, or Internet connection is required.

To review terminal and voice features:
1. Choose “Open Workspace” and select a disposable folder with the macOS picker.
2. Enter a shell command in the center terminal, or describe a task in the assistant panel.
3. For optional voice input, choose “Voice,” grant Microphone and Speech Recognition access, speak, then choose “Stop.” The transcript stays editable; nothing runs until the reviewer creates a plan, inserts it, and explicitly presses Enter.

The Mac App Store build is sandboxed. Shell commands operate within macOS permissions and the reviewer-selected workspace. The app has no telemetry, ads, cloud AI, or cloud account. The bundled Qwen2.5-Coder GGUF model and signed llama.cpp helper run locally. Deterministic planning and the terminal remain interactive during model warm-up.

Voice uses Apple’s Speech framework with on-device recognition required, no cloud fallback, a 30-second maximum, and no audio storage.

Searchable history stores heuristically redacted command text and execution metadata in a SQLCipher-encrypted database in the app container. Its random key is a device-only, non-synchronizing Keychain item. Command output is not persisted by default. “Clear all” removes history and in-memory adaptation. Authentication failure visibly falls back to memory-only history without plaintext database writes.
