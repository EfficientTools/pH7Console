NETWORK SERVER ENTITLEMENT — REQUIRED FOR ON-DEVICE LOCAL AI

pH7Console intentionally includes com.apple.security.network.server only for its bundled on-device language-model runtime. The main app launches the signed `llama-server` helper, which listens only on 127.0.0.1 on an OS-selected ephemeral port and requires a new random API key on every launch. The pH7Console process is its only client.

The helper never binds to 0.0.0.0, ::, a LAN address, or a public interface. It does not advertise a service or provide web, FTP, or file sharing. No prompt or terminal data leaves the Mac. The sandbox-inheriting helper contains only com.apple.security.app-sandbox and com.apple.security.inherit; the parent therefore needs the server entitlement for this local listener.

To verify local inference:
1. Choose “Open Workspace” and select a disposable folder.
2. Press Command-J if needed, enter “show the current git branch,” and choose “Create Safe Command Plan.”
3. The result is labeled “On-device model.” Nothing runs until the reviewer inserts it and explicitly presses Enter.
4. Press Command-B if needed, then open Settings → Privacy → “Authenticated loopback inference” for live status and the entitlement explanation.

No account, demo user, subscription, external hardware, or Internet connection is required. The app has no telemetry, ads, cloud AI, or cloud account. Its Qwen2.5-Coder model and llama.cpp helper are bundled and run locally.

Optional voice input uses Apple's Speech framework with on-device recognition required, no cloud fallback, a 30-second maximum, and no audio storage. The transcript remains editable and never executes automatically.

Searchable command history is heuristically redacted and stored in a SQLCipher-encrypted database in the app container. Its random key is a device-only, non-synchronizing Keychain item. Command output is not persisted by default. “Clear all” removes history and in-memory adaptation. Authentication failure falls back visibly to memory-only history without plaintext database writes.
