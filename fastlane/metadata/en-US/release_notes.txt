This release rebuilds pH7Console around persistent native PTYs and a genuine bundled local LLM. It adds full interactive shell and TUI support, high-throughput binary streaming, same-workspace shell recovery, safe risk-rated command plans, cancellable local generation, optional on-device push-to-talk drafts, private shell integration, SQLCipher-encrypted searchable history, encrypted-history-backed adaptation, deep links, stronger workspace file handling, and extensive reliability/performance coverage.
